# APK Deliverables & Download Guide

### Why `.zip` and `.apk` are hidden in the left file tree:
The AI Studio web editor automatically filters out archive and executable formats (`.zip`, `.apk`, `.tar`, `.gz`) from the file tree so the code editor does not attempt to open large binary files.
